# 📌 Pinterest Clone (MERN Stack)

A full-stack Pinterest-inspired web application built using the MERN stack.

## 🔧 Major Technologies Used

### Frontend
- **React.js** (v19) – UI development
- **Vite** – Frontend build tool
- **React Router v7**
- **Zustand** – State management
- **React Query** – Data fetching
- **ImageKit** – Media handling

### Backend
- **Node.js**
- **Express.js**
- **MongoDB** – NoSQL database
- **Mongoose** – ODM for MongoDB

### Others
- **Axios** – HTTP client
- **Emoji Picker**, **React Colorful**, **Infinite Scroll**
- **ESLint** – Code linting
